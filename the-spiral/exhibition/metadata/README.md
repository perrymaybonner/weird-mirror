# Curiosity Loop: life, death, transformation, return

The spiral as a continuous movement through states of being. It opens at the centre with birth and emergence, widens through growth, erodes through death and loss, and turns into rebirth, memory and ancestry, ending on the same Kongo cosmogram it began with, so the viewer realises the exhibition has been moving in a circle. References: Hilma af Klint, the Kongo cosmogram (dikenga dia Kongo), Robert Smithson and Ana Mendieta. Smithson and Mendieta are still in copyright, so the Death section uses public-domain works that echo their ideas (entropy, shifting earth, ruin, the body returning to the land) rather than their images.

## Descriptions

Each record has a `descriptionSource`:

- `museum`: the museum's own text, unchanged
- `museum (abridged)`: the museum's own text, shortened or lightly trimmed without changing its meaning
- `museum (abridged) + context`: museum text plus one added sentence of context written for this exhibition
- `written for this exhibition`: written for this exhibition from the museum/Commons record and what is visible in the image

Titles, dates and makers come from the museum record (for Commons files, from the file
description, checked by hand). Nothing is invented; missing fields are `null`.
