09/28 I created a flow for my image image gallery concept. Flow
1. Person enters → “Awareness”
Photos slowly orbit around the screen in a loose spiral.
Their movement affects the spiral slightly.

↓
2. Hands appear → “Reveal”
Detect both hands.
Photos suddenly snap from the spiral into a grid.
↓
3. Gesture toward a photo → “Focus”
Recognize a pointing gesture or hand proximity to a particular image.
The selected image fills the screen.
↓
4. Exploration → “Distortion”
Hand distance from camera controls zoom.
The user gets a few seconds to investigate.
↓
5. Interaction disappears → “Forget”
If the user stops moving, the image slowly begins shrinking.
Other photos gradually reappear.
The selected image returns to the collection.
↓
6. Return → “Orbit”
Everything returns to the spiral.
I then gave claude this flow and asked to help me rebuild this, I asked it to ask me questions. I like my process so far. I think the flow works but am still deciding what images to use and how that affects the user. there are still thing I need to smooth out with the hand tracking, I want it to feel super smooth.
